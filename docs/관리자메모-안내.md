# 관리자 특이사항·연락 메모

관리자 신청자 명단의 ‘신청자 정보’에서 **특이사항·연락 메모**를 펼쳐 사용합니다. 모바일에서는 해당 신청자의 **상세**를 먼저 누릅니다.

## 최초 설치

1. `관리자메모-설치.sql` 파일 **전체**를 Supabase SQL Editor의 새 쿼리에 붙여넣어 실행합니다. 기존 신청 정보는 변경하지 않습니다.
2. 마지막 줄이 `select '10단계 관리자 메모 준비 완료' as result;`인지 확인합니다.
3. RLS 경고가 나오면 **Run without RLS**를 선택합니다. 스크립트가 RLS와 관리자 전용 조회 정책을 직접 설정하므로 편집기의 자동 RLS 추가는 필요하지 않습니다.
4. 결과에 **10단계 관리자 메모 준비 완료**가 나오면 관리자 화면을 새로고침합니다. 기존 프로젝트의 01·02단계 설정이 필요합니다. 파일을 다시 실행해도 메모는 유지됩니다.

## 사용

- ‘새 메모’에 연락 결과 등을 적고 **메모 저장**을 누릅니다. 1건당 1,000자까지 입력할 수 있습니다.
- ‘전화 부재’, ‘입금 안내 문자 발송’, ‘입금 미확인 지속’ 버튼은 입력칸에 문구를 추가합니다. 저장 버튼을 눌러야 등록됩니다.
- 작성 시각(한국시간)이 자동으로 남고 새 메모부터 보입니다. 처음에는 최근 5건을 표시하며 이전 메모도 더 불러올 수 있습니다.
- 메모가 있으면 PC 목록에 최근 내용이, 모바일 목록에는 메모 건수가 표시됩니다.
- 메모는 누적 기록입니다. 내용을 정정하려면 후속 메모를 남깁니다.
- 저장은 입금·연락·취소 상태를 변경하거나 문자를 보내지 않습니다. 기존 처리 버튼은 별도로 사용합니다.
- 신청자의 날짜 변경·취소 뒤에도 같은 신청의 메모가 유지됩니다. 신청 기록을 파기하면 연결된 메모도 함께 삭제됩니다.
- 일반 참가자에게는 공개되지 않으며 관리자만 조회·추가할 수 있습니다. 운영에 필요한 내용만 기록합니다.
