## 접수를 열기 전

관리자 회차 설정에서 확정된 집결 시간·코스가 기본값으로 표시됩니다. 기존 DB의 비어 있는 값을 채우려면 회차별로 설정을 저장합니다. 이미 저장된 값이 있으면 그 값을 우선합니다. 안내 예정일도 함께 확인합니다.

기존 동의문은 그대로 복사하지 않습니다. 다음을 확정해야 합니다.

- 실제 수집 항목: 신청자명, 시·군·구, 연락처, 참여 인원, 입금자명. 홈페이지는 주민등록번호·상세주소·환불계좌를 수집하지 않습니다.
- 여행자보험에 주민등록번호가 필요하다면 별도 수집 필요성·방식·접근권한을 먼저 확정합니다. 기존 문구만으로 신청서에 추가하지 않습니다.
- 개인정보 보유 기간은 **신청일로부터 1년 후 파기**로 확정했습니다. 현재 자동 파기 기능은 없으므로 기간 만료 자료는 관리자가 별도로 파기해야 합니다. 연결된 신청 처리 이력과 백업의 보유·파기 기준도 함께 관리합니다.
- 사진 촬영·완보자 날짜코드 사진방 공유와 공식 공개 갤러리 공유를 각각 별도 선택 동의로 기록합니다. 비동의해도 신청할 수 있습니다. 신청자 본인의 동의만 기록하며 일행은 별도 확인합니다. 관리자는 각 범위의 동의를 확인하고 게시 위치를 선택합니다. 기존 범위 동의는 공개 게시 동의로 바꾸지 않습니다.
- 금요일은 진행 확정 공지 기준일입니다. 새 환불 신청 마감은 체험 3일 전입니다. 마감은 체험 3일 전 밤 11시 59분(한국시간)까지 취소 문자 접수입니다. 마감 후 환불 기준은 사무국 확인 대상입니다. **참가자 취소는 이체수수료 500원을 제외하고 환불하며 농협 계좌는 수수료가 없습니다. 주최 측 취소는 수수료 공제 없이 전액 환불**합니다. 미입금자는 체험 전날 안내하며, 시스템이 자동 취소하지 않습니다.
- 관리자 정책란이 비어 있으면 위 확정 기준의 초안이 표시됩니다. 기존에 저장한 문구는 덮어쓰지 않으므로, 이전 문구를 저장한 경우 관리자 화면에서 최신 기준으로 수정 후 저장합니다.

정책 설정에 최종 문구를 입력하고 ‘접수 개방 허용’을 선택합니다. 다음으로 각 회차에서 ‘신규 신청 접수 열기’를 선택하고 저장합니다. 정책이 미승인이거나 시간·코스·안내일이 비어 있으면 개방되지 않습니다.

## 일상 관리

1. 신청자는 신청 완료 후 입금 안내를 확인합니다. 자동 문자로 접수증이 발송되지는 않습니다.
2. 관리자는 은행에서 입금을 직접 확인합니다. 명단의 인원·입금자명·총액과 대조하고 ‘입금 확인’을 누릅니다. 부분입금 처리 기능은 아직 없습니다.
3. 안내 문자를 직접 보내고, 중요한 취소 안내는 응답 또는 통화로 전달 여부를 확인합니다. 확인한 신청을 ‘연락 확인 완료’로 표시합니다.
4. 연락 대상은 신청 건 단위입니다. 대표 신청자의 전화번호 하나로 일행 전체를 안내합니다. 일행별 개별 연락이 필요하면 수집·신청 구조를 추가해야 합니다.
5. 진행 안내 예정일은 자동 예약 발송이 아닙니다. 실제 문자 서비스 연결 전에는 일정표나 업무 캘린더에도 업무를 등록합니다.

## 날짜 변경

해당 신청의 ‘날짜 변경’을 열어 새 회차를 선택합니다. 현재 접수 중이고 자리가 있는 회차만 이동할 수 있습니다. 기존 신청번호와 최초 신청 회차는 유지하며, 새 회차 명단에 ‘변경자’로 표시됩니다. 기존 회차에서 차지하던 정원은 해제되고 새 회차 정원에 반영됩니다.

변경하면 ‘안내 필요’로 돌아갑니다. 새 일정에 대해 다시 안내하고 확인합니다. 환불 완료된 신청은 이동할 수 없으며, 새 신청으로 처리해야 합니다. 회차 취소 후 아직 환불 전인 신청은 협의 후 다른 회차로 이동하면 환불 대기가 해제됩니다.

## 접수 마감과 운영 취소

- **접수 마감:** 신규 신청을 막을 뿐 기존 참여 예정자는 유지합니다. 정원이 차면 접수 개방 표시와 관계없이 신규 신청을 막습니다.
- **운영 취소:** 회차 안의 확인 절차를 거쳐 확정합니다. 현재 참여 예정자 전원(변경 유입자 포함)을 취소하고 ‘안내 필요’로 되돌립니다. 입금 확인자는 ‘환불 대기’가 됩니다.
- 운영 취소 버튼만으로 문자가 발송되거나 은행 환불이 실행되지는 않습니다.
- 해당 회차를 필터링하고 취소 안내·날짜 변경·환불 업무를 처리합니다. 실제 송금이 끝난 후 ‘실제 환불 완료’를 누릅니다. 환불 사유와 수취 은행을 확인해 참가자 취소는 수수료 500원(농협 0원), 주최 측 취소는 0원을 적용합니다. 현재 화면은 환불 완료 여부를 기록하며 실환불액·은행·수수료를 별도 필드로 저장하거나 계산하지 않습니다. 환불 이체내역은 정산 자료로 별도 관리합니다.
- 취소 회차를 다시 열기 위한 화면은 없습니다. 실수로 취소하지 않도록 확인 문구와 체크 절차가 있습니다.

## 기록과 접근권한

처리 시각은 한국시간으로 표시합니다. 기록에는 관리자 UID, 신청번호, 변경 전후 운영 상태가 남습니다. 전화번호를 작업 로그에 중복 저장하지 않습니다. 일반 참가자와 관리자 권한이 없는 로그인 계정은 명단·로그를 조회할 수 없습니다. 데이터베이스 소유자는 기록을 변경할 수 있으므로 외부 감사용 위변조 방지 보관 시스템은 아닙니다.
