# 협회 표기와 첫 화면

상단에는 협회 심벌만, 최하단에는 한글·영문 풀네임 가로형 로고를 배치합니다. 사용자가 제공한 `로고_전체_부산치유협회.ai`의 해당 도안을 각각 웹용 투명 PNG로 렌더링했습니다. 도안·글자·색상을 다시 그리거나 변경하지 않았습니다. 로고 자체 색상은 보존하고 사이트 UI는 사용자가 제공한 짙은 초록·아이보리·골드 계열로 구성했습니다.

사업 배경은 결과보고서 제출문과 제1장 사업개요의 목적·범위를 요약했습니다. 보고서는 2025년 결과물로 확인되어 현재 2026년 모집 일정과 혼동할 수 있는 과거 기간·실적·인명은 홈페이지에 옮기지 않았습니다. 보고서 원문과 내부 정보는 저장소에 게시하지 않습니다.

오륙도 고화질 사진은 사용자가 ZIP으로 제공한 원본 JPG(4167×2778)를 `public/images/oryukdo-intro.jpg`에 연결했습니다. 사진 내용·색상은 변경하지 않았습니다. 모바일에서는 섬과 등대가 잘리지 않도록 사진 전체가 보이게 표시합니다.

첫 화면은 서버가 전달하는 초기 화면부터 사진 덮개를 배치하여 홈페이지가 먼저 비치는 현상을 방지합니다. 사진 로딩이 끝난 다음 약 1.8초 동안 보여주고, 1.1초 동안 그라데이션과 함께 상단으로 이동하며 사라집니다. 바로 들어가기 버튼이 있으며 한 탭의 세션에서 한 번만 표시합니다. 이미지 로딩 오류 시 덮개를 해제하며, 로딩이 지연되어도 최대 8초 후 해제합니다. 자바스크립트 비활성·동작 줄이기 설정과 신청 영역 바로가기에서는 홈페이지를 바로 사용할 수 있습니다. 신청과 관리자 로그인 기능은 이 연출과 관계없이 작동합니다.


신청 날짜 제목은 초록색과 골드 밑줄로 강조합니다. 날짜 선택과 필수 입력·확인 항목에는 빨간 별표를 사용하고 사진 동의 두 항목은 선택사항을 유지합니다. 주의사항은 네 개의 아이콘 카드로, 코스와 함께하는 여섯 활동은 별도 아이콘 목록으로 안내합니다.


안내 문장은 문장 단위로 줄을 나누어 읽기 쉽게 표시합니다. 사무국 문의 문구에는 `010-9679-9817, 문자 연락`을 함께 표기합니다. 반환점은 카메라 아이콘의 휴식·포토타임, 자가회복은 마사지건 아이콘으로 안내합니다. ‘참가 전 자주 확인하는 내용’ 버튼은 메인과 상세 안내 페이지 각각의 문답 영역으로 같은 페이지 안에서 스크롤합니다. FAQ의 우천 안내에서는 10월 23일 예외 문구를 제외하고, 도구 안내에 연구진 선정 마사지건·괄사와 테이핑 시 무릎 위까지 충분히 올라오는 긴바지 권장을 반영했습니다.


현재 색 조합은 `#102B24`(짙은 초록), `#2E7D5B`(초록), `#F5F1E6`(아이보리), `#B08D57`(골드), `#F2C14E`(밝은 골드)입니다. 색상 조정은 `app/theme.css`에서 공통 관리합니다. 짙은 초록 프로그램 소개 패널, 아이보리 카드, 골드 테두리·포인트를 사용하고 금속성 장식은 얇은 골드 선과 포인트 정도로 제한했습니다. 본문과 배경의 명암을 유지하며 필수 입력의 빨간 별표는 그대로 둡니다.

소개 문구와 프로그램 이름을 ‘자가회복’으로 통일했습니다. 준비물·건강 상태·문자 확인 카드에는 각각 가방·건강·문자 아이콘을 배치하고, 모바일의 불필요한 빈 열이 생기지 않는 구조로 변경했습니다.


## 실사 사진 배치와 전환

사용자가 제공한 `오륙도홈페이지용사진.zip`의 사진 17장을 웹용 WebP로 변환해 사용합니다. 원본 픽셀과 동일한 무손실 WebP로 제공하며 전체 크기는 약 7.3MB입니다. 현재·앞뒤 사진만 우선 불러옵니다. 원본을 확대 생성하거나 내용을 바꾸지 않았습니다.

| 화면 위치 | 사용자 원본 파일명 |
| --- | --- |
| 메인 첫 사진 | 오륙도_이기대에서본전경 |
| 안전걷기 테이핑 | 오륙도_테이핑완성 |
| 바른자세 걷기 | 오륙도_이기대가는길 |
| 자가회복 프로그램 | 오륙도_마사지건하는모습 |
| 해파랑길·치마바위 코스 | 오륙도_이기대전경 |
| 남파랑길·신선대 코스 | 오륙도_이기대에서본전경 |

사진 정보와 순서는 `lib/site-photos.ts`, 메인 전환은 `components/hero-photos.tsx`, 사진 배치와 색상은 `app/theme.css`에서 관리합니다. 영상은 사용하지 않습니다. 레퍼런스 사이트는 작업 환경의 네트워크 접근 제한으로 직접 확인하지 못했으며, 사용자의 사진·배치 지정과 기존 초록·아이보리·골드 조합을 기준으로 구성했습니다.

첫 방문의 오륙도 인트로가 사라진 뒤 메인은 지정 전경에서 시작합니다. 메인 사진은 총 11장입니다. 등록·안전교육·준비운동·테이핑·포토타임·체험 물품 사진은 인트로가 완전히 끝난 뒤부터 3초마다 0.9초 동안 겹쳐 전환됩니다. 사진의 밝기에 관계없이 글을 읽을 수 있게 초록 그라데이션을 겹칩니다. 기존 11·12번의 작은 자가회복 도구·활동 사진은 메인 전환에서 제외했습니다. 현재·앞뒤 사진만 화면에 불러옵니다.

일시정지·재생·이전·다음 버튼을 제공합니다. 마우스나 키보드 초점, 이전·다음 조작으로는 자동 전환을 멈추지 않습니다. 사용자가 일시정지를 누르거나 브라우저가 숨겨진 경우에만 멈춥니다. 재생 버튼으로 다시 시작합니다. 동작 줄이기 설정에서는 부드러운 전환 효과를 없애고 3초마다 사진만 교체합니다. 확대 효과는 모든 환경에서 제거했습니다. 직접 선택한 사진과 재생 상태는 저장하지 않습니다.

하단은 진한 초록 바탕에 골드 구분선·원형 선 그래픽과 은은한 오륙도 사진을 겹칩니다. 하단 로고는 기존 투명 PNG를 사용하며, 어두운 배경에서 읽히도록 CSS로 밝은 단색을 적용합니다. 원본 로고 파일은 보존하고 흰색 받침은 사용하지 않습니다. 이번 디자인 변경에는 추가 SQL이 필요하지 않습니다.


제공된 원본의 가로 해상도는 약 341~883px입니다. 파일은 원본 크기와 픽셀을 보존하며 더 큰 디테일을 생성한 것으로 표시하지 않습니다. 고해상도 원본이 제공되면 사진 파일을 교체할 수 있습니다. 무손실 사진의 파일명을 변경하여 이전 압축본의 브라우저 캐시와 구분했습니다.

안내 카드의 공통 제목은 20px, 본문은 15px, 본문 줄간격은 1.9로 관리합니다. 안전수칙 네 장은 좌상단·우하단(1·4번)을 샴페인 골드, 우상단·좌하단(2·3번)을 세이지 그린으로 대각선 배색합니다. 같은 색의 카드끼리 아이콘·번호·테두리·본문 배경을 맞추고 글자 규격과 여백은 네 장 모두 통일합니다. 설명 길이에 관계없이 배경이 카드 끝까지 채워집니다. 모바일 한 열에서는 1·4번 골드, 2·3번 그린의 순서를 유지합니다. 준비 카드의 아이콘과 제목은 같은 행에서 세로 중앙 정렬하며 설명은 다음 행에 배치합니다. 거리 숫자 앞에는 글자 크기에 비례한 고정 여백을 두어 공백 축소의 영향을 받지 않게 합니다.

메뉴·갤러리 탭·신청 및 FAQ 이동 링크는 `components/site-link.tsx`를 공통 사용합니다. 같은 URL을 다시 누르는 경우에도 해당 위치로 스크롤하며, 신청서가 있는 같은 페이지는 새로고침하지 않습니다. 다른 페이지로의 이동은 Next.js 링크를 유지하고 이동이 지연될 때 하단에 상태를 표시합니다. 일반 클릭·Enter 키는 이동을 실행하며 Ctrl/Cmd 클릭과 새 탭 열기는 브라우저 기본 동작을 유지합니다. 동작 줄이기 설정에서는 즉시 스크롤합니다.

배포 전 이동 확인: 갤러리 → 체험 신청 → 맨 위로 스크롤 → 체험 신청을 다시 클릭, 홈 로고 반복 클릭, 홈·소개 페이지의 FAQ 버튼 반복 클릭, 공식 갤러리 ↔ 완보자 사진방 왕복을 PC·모바일 너비에서 확인합니다. 같은 페이지의 신청 이동 전후로 작성 중인 값이 유지되는지 확인하되 실제 신청 제출은 하지 않습니다.

메인 마지막 사진의 문구는 “정성껏 준비한 체험의 추억들”입니다. 신청 영역 제목 바로 아래, 앞으로의 체험 일정보다 위에 운영 완료 회차를 실버 톤 카드로 표시합니다. 각 카드에는 운영 완료·날짜·코스만 표시합니다. 운영자가 실제 완료를 확인한 1~5회차(4/25·5/9·5/30·9/19·10/3)는 `lib/confirmed-history.ts`에 공개 기록으로 보존하므로 DB에 과거 신청 자료를 등록하지 않았어도 항상 보입니다. 이후 DB에서 실제 완료로 표시한 회차는 날짜 중복 없이 합쳐 표시합니다. 공개 운영 이력 표시와 관리자용 신청자 명단 등록은 별도이며, 공개 카드에는 신청 기능이 없습니다.
