# 협회 표기와 첫 화면

상단에는 협회 심벌만, 최하단에는 한글·영문 풀네임 가로형 로고를 배치합니다. 사용자가 제공한 `로고_전체_부산치유협회.ai`의 해당 도안을 각각 웹용 투명 PNG로 렌더링했습니다. 도안·글자·색상을 다시 그리거나 변경하지 않았습니다. 로고 자체 색상은 보존하고 사이트 UI는 초록·보라 계열로 구성했습니다.

사업 배경은 결과보고서 제출문과 제1장 사업개요의 목적·범위를 요약했습니다. 보고서는 2025년 결과물로 확인되어 현재 2026년 모집 일정과 혼동할 수 있는 과거 기간·실적·인명은 홈페이지에 옮기지 않았습니다. 보고서 원문과 내부 정보는 저장소에 게시하지 않습니다.

오륙도 고화질 사진은 대화에 보이지만 작업 환경에 원본 파일이 전달되지 않아 아직 연결하지 않았습니다. 원본 JPG를 `public/images/oryukdo-intro.jpg`에 추가하고 `lib/branding.ts`의 welcomePhoto를 `/images/oryukdo-intro.jpg`로 설정하면 연출이 활성화됩니다. 임의의 대체 사진은 사용하지 않습니다.

첫 화면 연출은 사진 로딩이 끝난 다음 약 1.8초 동안 보여주고 0.7초 동안 사라집니다. 바로 들어가기 버튼이 있으며 한 탭의 세션에서 한 번만 표시합니다. 이미지 로딩 실패·자바스크립트 비활성·동작 줄이기 설정에서는 홈페이지를 바로 사용할 수 있습니다. 신청과 관리자 로그인 기능은 이 연출과 관계없이 작동합니다.
