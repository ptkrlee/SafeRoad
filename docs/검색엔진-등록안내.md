# 구글·네이버 검색 등록

대표 주소는 `https://safetyroad.vercel.app/`입니다. GitHub 변경에 따른 Vercel 배포가 Ready로 끝난 뒤 진행합니다. 검색 등록과 순위는 서로 다르며, 신청만으로 즉시 검색 노출이나 상위 순위가 보장되지는 않습니다.

## 홈페이지에 반영된 내용

- 검색 제목·설명, 공유용 사진, 공개 페이지별 대표 주소(canonical).
- 부산치유협회와 홈페이지 정보를 나타내는 구조화 데이터.
- `https://safetyroad.vercel.app/sitemap.xml`: 홈·프로그램 소개·공식 공개 갤러리만 포함.
- `https://safetyroad.vercel.app/robots.txt`: 공개 페이지 수집 허용. 관리자·완보자 사진방은 기존 noindex를 유지. 접근 권한은 기존 로그인·입장코드로 별도 관리.
- Vercel Preview 환경은 검색 제외.

## 1. 사이트 소유권 확인

구글과 네이버에서 각각 등록해야 합니다. 소유권 확인 메타 태그는 공개되는 확인용 값이며 Supabase 키와는 별개입니다.

1. Google Search Console (`https://search.google.com/search-console/`)에 로그인합니다.
2. 속성 추가에서 **URL 접두어**를 선택하고 `https://safetyroad.vercel.app/`를 입력합니다. vercel.app 전체 도메인 소유권을 확인하는 방식은 선택하지 않습니다.
3. 확인 방법에서 **HTML 태그**를 선택합니다. `<meta name="google-site-verification" content="...">`의 content 안 값만 복사합니다.
4. 네이버 서치어드바이저 (`https://searchadvisor.naver.com/`)에 로그인 → 웹마스터 도구 → 사이트 등록에서 같은 주소를 입력합니다.
5. **HTML 태그** 확인 방법을 선택하고 `<meta name="naver-site-verification" content="...">`의 content 안 값만 복사합니다.
6. Vercel 프로젝트 Settings → Environment Variables에 아래 두 항목을 **Production**으로 추가합니다. Config 유형을 사용할 수 있습니다.

| Key | Value |
| --- | --- |
| GOOGLE_SITE_VERIFICATION | 구글 메타 태그의 content 값 |
| NAVER_SITE_VERIFICATION | 네이버 메타 태그의 content 값 |

7. 변경을 저장하고 Production을 **Redeploy**합니다. 환경변수만 저장해서는 기존 배포에 적용되지 않습니다.
8. 배포가 Ready가 되면 구글·네이버 화면으로 돌아가 **소유권 확인**을 누릅니다. 등록 후에도 확인 값을 삭제하지 않습니다.

태그 전체를 담당 개발자에게 전달해 코드에 반영하는 방식도 가능합니다. 네이버·구글 계정의 비밀번호를 전달할 필요는 없습니다.

## 2. 수집 요청

- 구글: Sitemaps 메뉴에서 `sitemap.xml`을 제출합니다. URL 검사에서 대표 주소와 `/guide`를 검사하고 색인 생성 요청을 진행합니다.
- 네이버: 요청 → 사이트맵 제출에서 `https://safetyroad.vercel.app/sitemap.xml`을 제출합니다. 요청 → 웹 페이지 수집에서 대표 주소와 `/guide`를 요청합니다. 메뉴 명칭은 서비스 화면 변경에 따라 다를 수 있습니다.
- 관리자 주소나 완보자 사진방은 제출하지 않습니다. RSS는 현재 제공하지 않으므로 RSS 제출은 생략합니다.

며칠에서 수 주 이상 걸릴 수 있으며, 각 서비스의 색인·수집 현황으로 확인합니다. 협회 공식 홈페이지·블로그와 사업 소개 게시물에서 프로그램 이름과 홈페이지 링크를 자연스럽게 연결하면 발견에 도움이 됩니다. 키워드를 반복해서 넣거나 숨은 글자를 추가하지 않습니다.

대표 도메인이 바뀌면 `lib/seo.ts`의 주소, 소유권 확인 속성, 기존 주소의 리디렉션을 함께 변경합니다.
